## Contract
`ExpenseListProps` gains an optional callback:
```ts
interface ExpenseListProps {
  expenses: Expense[];
  onDelete?: (id: string) => void;
}
```
Each rendered row gets a delete button when `onDelete` is provided:
- `<button>` with `aria-label={`Delete ${expense.description}`}` and visible text/icon
- onClick → `onDelete(expense.id)`
- When `onDelete` is NOT provided, render NO delete button (keeps the component
  usable without delete; existing tests that pass no `onDelete` stay green).

App wiring (done by main agent, not this sub-agent): `handleDelete(id)` →
`removeExpense(id)` from the store → refresh list.

## Tests (add to existing file — keep all current tests passing)
- with `onDelete`: a delete button renders per row, `aria-label` includes the description
- clicking a row's delete button calls `onDelete` once with that expense's id
- without `onDelete`: no delete buttons render
