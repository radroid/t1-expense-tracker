## Contracts

### lib/categoryTotals.ts
```ts
import type { Expense } from './expense'
import type { Category } from './category'

export interface CategoryTotal {
  category: Category | null     // null for uncategorized + orphans
  total: number
}

// Groups expenses by categoryId, sums amount per group.
// - Each Category in `categories` that has ≥1 expense → one entry { category, total }.
// - Expenses with no categoryId OR a categoryId not in `categories` (orphans from
//   deleted categories — see TD.6) → bucketed into a single { category: null, total }.
// - Categories with zero expenses → omitted (no zero-total rows).
// - Pure. Does not mutate inputs.
// Return order is unspecified — caller decides if it wants to sort.
export function spendingByCategory(
  expenses: Expense[],
  categories: Category[],
): CategoryTotal[]
```

### components/SpendingByCategory.tsx
```ts
interface SpendingByCategoryProps {
  expenses: Expense[]
  categories: Category[]
}
export function SpendingByCategory(props: SpendingByCategoryProps): JSX.Element
```
- Calls `spendingByCategory` and renders one row per non-zero group: a colored
  swatch (category color, or a neutral gray for the `null`/uncategorized bucket),
  the category name (or "Uncategorized"), and the total currency-formatted.
- Sort rows by `total` descending (biggest spend first).
- If there are NO expenses → render a small empty-state message
  ("No spending yet."). If there are expenses but only the `null` bucket → show that.
- Currency formatting consistent with `RunningTotal` / `ExpenseList` (`Intl.NumberFormat`
  USD, 2 dp). Acknowledge TD.1 (formatter duplicated three times now) but keep this
  feature pure of the dedup — TD.1 stays a separate refactor.
- Pure presentational. No store/db import.

## Tests

  - empty expenses → []

  - multiple expenses same category → summed
  - mixed categories → one entry per category present, each sum correct
  - expense with no `categoryId` → null bucket
  - expense with `categoryId` not in `categories` (orphan) → null bucket
  - mix of null/orphan/normal → null bucket sums all unknowns
  - does not mutate inputs (snapshot lengths)

  - empty expenses → empty-state message
