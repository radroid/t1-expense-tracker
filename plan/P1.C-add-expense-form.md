## Contract
```ts
import type { ExpenseInput } from '../lib/expense';

interface AddExpenseFormProps {
  onAdd: (input: ExpenseInput) => void;
}
export function AddExpenseForm(props: AddExpenseFormProps): JSX.Element;
```
Controlled inputs: amount (number), description (text), date (date, defaults to today).
On submit: build `ExpenseInput`, call `onAdd`, clear amount + description (keep date),
do NOT call `onAdd` if amount/description blank — show inline validation message instead.
The form does NOT touch the store or `createExpense` directly — it only emits `ExpenseInput`
via `onAdd`. App wiring is done separately by the main agent.

## Tests (RTL + user-event)
- typing + submit → `onAdd` called once with correct ExpenseInput shape
- amount + description cleared after submit, date retained
- blank amount or blank description → `onAdd` NOT called, validation message visible
- date defaults to today's date on mount

## Peer-review charter
Verify controlled inputs, onAdd contract exact, no store/db import, clears correctly,
basic accessibility (labels tied to inputs).
