# P2.C — Assign category to expense

Add a category picker to the (now unified) `ExpenseForm`. The lib + store already
thread `categoryId` (`ExpenseInput`/`Expense` have optional `categoryId`;
`validateExpenseInput` passes it through) — this feature is form + wiring only.

## Files (sub-agent allowlist)
- `src/components/ExpenseForm.tsx` (modify)
- `src/components/ExpenseForm.test.tsx` (modify)
- `src/components/ExpenseForm.css` (modify — style the new field)

`src/App.tsx` is NOT in the allowlist — the main agent passes the `categories` prop.

## Contract
`ExpenseFormProps` gains a required `categories` prop:
```ts
import type { Category } from '../lib/category'
interface ExpenseFormProps {
  initial?: ExpenseInput
  categories: Category[]          // NEW
  submitLabel: string
  onSubmit: (input: ExpenseInput) => void
  onCancel?: () => void
  clearOnSubmit?: boolean
}
```
- New controlled `<select>` field labelled "Category" (`htmlFor`/`id` `expense-form-category`).
- Options: a first option `value=""` labelled "Uncategorized", then one `<option>` per
  `categories` entry (`value={category.id}`, text `{category.name}`).
- State: `const [categoryId, setCategoryId] = useState(initial?.categoryId ?? '')`.
- On valid submit: include `categoryId: categoryId || undefined` in the `onSubmit` input
  (empty string → `undefined`, NOT `''` — keep the data clean).
- `initial?.categoryId` present → select pre-selected to that category.
- `clearOnSubmit`: clears amount + description (as today); KEEPS date AND category
  (friendlier for entering several expenses in one category).
- Existing behaviour (amount/description/date, blank-field guards, Cancel) unchanged.
- Semicolon-free.

## Tests (update ExpenseForm.test.tsx — all 17 existing tests must still pass)
The existing tests render `<ExpenseForm>` without `categories` — now required. Add a
small default (e.g. a `setup`/helper or a shared `categories` const) so existing tests
still construct a valid element. Then add:
- renders an "Uncategorized" option + one option per category passed in
- selecting a category + valid submit → `onSubmit` input has `categoryId` = that id
- submitting with "Uncategorized" selected → `onSubmit` input `categoryId` is `undefined`
- `initial.categoryId` set → the select is pre-selected to that category
- `clearOnSubmit` after submit → category selection is retained (not reset)

## Peer-review charter
Verify the `categories` prop is wired correctly, `categoryId: categoryId || undefined`
(no empty-string leak into the data), pre-fill from `initial.categoryId` works, existing
17 tests still pass, the picker doesn't break the blank-field guards or Cancel.
