## Contract
```ts
// DB name 'expense-tracker', object store 'expenses', keyPath 'id'.
export function openDb(): Promise<IDBDatabase>;
export function addExpense(e: Expense): Promise<void>;
export function getAllExpenses(): Promise<Expense[]>;
export function updateExpense(e: Expense): Promise<void>;
export function removeExpense(id: string): Promise<void>;
```
Import `Expense` type from `../lib/expense`. The store is a thin typed wrapper —
no validation here (that's P1.A's job).

## Tests
Use `fake-indexeddb` (added via setup.ts import). Reset DB between tests
(`indexedDB.deleteDatabase('expense-tracker')` in `beforeEach`).
- add then getAll → returns the expense
- add multiple → getAll returns all
- update → getAll reflects the change
- remove → getAll no longer contains it
- getAll on empty store → []
