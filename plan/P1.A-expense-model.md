## Contract
```ts
export interface Expense {
  id: string;
  amount: number;        // > 0, dollars (2dp)
  description: string;   // non-empty after trim
  date: string;          // ISO 'YYYY-MM-DD'
  categoryId?: string;
  recurring?: boolean;
}

export interface ExpenseInput {
  amount: number;
  description: string;
  date: string;          // 'YYYY-MM-DD'
  categoryId?: string;
  recurring?: boolean;
}

// Validates: amount > 0 (finite), description non-empty after trim,
// date matches /^\d{4}-\d{2}-\d{2}$/ AND is a real calendar date.
// Trims description. Generates id via crypto.randomUUID().
// Throws Error with a clear message on any invalid field.
export function createExpense(input: ExpenseInput): Expense;
```

## Tests
- valid input → Expense with generated id, trimmed description, fields copied
- amount <= 0, NaN, Infinity → throws
- empty / whitespace-only description → throws
- malformed date ('2026-13-40', 'not-a-date', '') → throws
- optional categoryId / recurring passed through when present

## Peer-review charter
Verify validation rejects all invalid cases; id is unique per call; no IndexedDB/React imports (pure lib).
