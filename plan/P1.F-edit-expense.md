```ts

// YYYY-MM-DD date); returns the cleaned fields. Throws on invalid — same
// messages as today.
```

All 15 existing `createExpense` tests must still pass unchanged.

### components/ExpenseList.tsx — add edit affordance
`ExpenseListProps` gains `onEdit?: (expense: Expense) => void`. Each row renders an
Edit button (mirror the existing Delete button) when `onEdit` is provided:
`aria-label={`Edit ${expense.description}`}`, onClick → `onEdit(expense)`.
Update `ExpenseList.css` grid-template-columns for the extra column.
Keep the file's existing style (semicolons) — consistency within the file.

### components/EditExpenseForm.tsx — new
```ts
import type { Expense, ExpenseInput } from '../lib/expense'
interface EditExpenseFormProps {
  expense: Expense
  onSave: (input: ExpenseInput) => void
  onCancel: () => void
}
export function EditExpenseForm(props: EditExpenseFormProps): JSX.Element
```
Controlled amount/description/date inputs **pre-filled from `expense`**. Same blank-field
validation guards as `AddExpenseForm` (read it for the pattern: blank/NaN amount, blank
description, empty date → inline `role="alert"` message, do not call `onSave`). On valid
submit → `onSave({ amount, description, date })`. A Cancel button → `onCancel()`.
New file → semicolon-free (Vite scaffold convention).
