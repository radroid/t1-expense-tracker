## Contract
```ts
import type { Expense } from '../lib/expense';

interface ExpenseListProps {
  expenses: Expense[];
}
export function ExpenseList(props: ExpenseListProps): JSX.Element;
```
Renders expenses **newest-first** (sort by `date` descending; stable for equal dates).
Each row shows: amount (formatted `$0.00`), description, date.
Empty `expenses` → an empty-state message ("No expenses yet.").
Pure presentational component — no store/db import, does not mutate the prop.

## Tests (RTL)
- renders all expenses passed in
- order is newest-first regardless of input order
- amount formatted as currency ($1,234.50)
- empty array → empty-state message shown
